# AI Production Review Checklist

- [ ] AI output treated as a draft, not an authoritative source
- [ ] Research brief checked before reviewing scripts
- [ ] Every source URL opened and evaluated
- [ ] Claims marked NEEDS_VERIFICATION removed or independently verified
- [ ] No fabricated citations, quotes, statistics, or product capabilities
- [ ] Both language versions preserve factual scope and caveats
- [ ] Cybersecurity examples remain authorized, safe, and defensive
- [ ] Visual and audio assets have appropriate rights
- [ ] Human editor approved final export
- [ ] No automatic publishing action was triggered
