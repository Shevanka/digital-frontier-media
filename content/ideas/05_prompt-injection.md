# Prompt Injection Explained

- Pillar: AI / Cybersecurity
- Status: Evergreen / research required
- Audience: Developers and general technology audience

## Editorial angle
Explain how instructions embedded in untrusted content can conflict with an AI application's intended instructions, especially when a model can use tools or access private context.

## Key questions
- What is the difference between direct and indirect prompt injection?
- Why is retrieved content untrusted input?
- Why are prompt-only defenses insufficient?
- How can systems isolate data, constrain tools, and require approval for sensitive actions?

## Accuracy notes
Use defensive framing. Avoid claiming that a single prompt or filter completely solves prompt injection.
